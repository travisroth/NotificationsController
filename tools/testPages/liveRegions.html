Live region test page

Each button updates a live region, so NVDA reports it and NotificationsController logs it. Serve this page from two host names to test site scoping, for example run python -m http.server 8000 in this folder and open both http://localhost:8000/liveRegions.html and http://127.0.0.1:8000/liveRegions.html.
